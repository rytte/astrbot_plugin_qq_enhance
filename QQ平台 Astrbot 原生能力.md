#### QQ平台 Astrbot 原生支持

> 4.27.4 版本逐项手动测试并记录

##### 消息收发

| 消息类型                            | 接收（❌️为可以接收但无响应）               | 发送                                |
| ----------------------------------- | ----------------------------------------- | ----------------------------------- |
| 文本                                | ✅️                                         | ✅️                                   |
| 图片、表情包                        | ✅️（需要模型支持）                         | ✅️（表情包会以图片形式发回）         |
| 动图                                | 只能看到静态预览帧                        | ✅️                                   |
| 语音                                | ✅️（需要配置STT模型）                      | ✅️                                   |
| 文件                                | ❌️（文件能接收保存，但不会自动识别和理解） | ✅️                                   |
| emoji                               | ✅️                                         | ✅️                                   |
| QQ 小表情                           | ❌️                                         | ❌️                                   |
| QQ 动态表情                         | ❌️                                         | ❌️                                   |
| 骰子、猜拳                          | ❌️                                         | ❌️                                   |
| 戳一戳                              | ❌️                                         | ❌️                                   |
| 窗口抖动                            | ❌️                                         | ❌️                                   |
| @                                   | ✅️                                         | ✅️（需要打开用户识别）               |
| 引用回复                            | ✅️                                         | ❌️（仅支持每次都引用）               |
| 合并转发                            | ❌️                                         | ❌（程序支持但未提供Tool给模型使用） |
| JSON 卡片、分享、音乐、位置、联系人 | ❌️                                         | ❌️                                   |

##### 其它通用能力

| 能力                                      | 支持情况 | 说明                                                         |
| ----------------------------------------- | -------- | ------------------------------------------------------------ |
| 跨会话能力                                | ✅️        | （上下文不共享）（需要告诉模型地址格式 `实例名:FriendMessage:<QQ号>  实例名:GroupMessage:<群号>`）（不支持使用群名） |
| 群聊文本、图片、语音、视频、文件、引用、@ | ✅️❌️       | 文件不支持                                                   |
| 查询群资料、群成员、群主和管理员          | ❌️        | 只能获取到群名群号和发言人信息                               |
